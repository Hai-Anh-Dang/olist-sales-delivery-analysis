# Power BI

This folder documents the planned report. A completed PBIX or public report is not included in this release.

| Planned page | Business purpose |
| --- | --- |
| Performance Overview | Compare purchase-month activity and delivered merchandise value. |
| Categories and Sellers | Examine commercial contribution alongside seller-associated delivery outcomes. |
| Delivery and Cancellations | Identify material state/month cohorts and cancellation counts. |

Keep order, item, and payment facts separate. Category and seller selections require an explicit qualifying-order set for order-level measures. Use calendar-date comparisons for on-time delivery and disclose missing-date exclusions.
